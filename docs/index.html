Methodology Overview

This demo showcases the predictive capability of AlgoGPT, a foundation model architecture adapted for the microstructure and dynamics of Indian equity index derivatives (NIFTY & BANKNIFTY). The forecasting pipeline operates through four modular stages:

⚡ 1. K-Line Tokenization

Continuous candlestick bars (Open, High, Low, Close, Volume, Amount) are quantized using Binary Spherical Quantization (BSQ) into hierarchical coarse and fine subtokens, preserving geometric candlestick formations.

🧠 2. Autoregressive Backbone

The Kronos Causal Transformer (4M parameters) processes up to 512 historical context bars, attending across temporal market patterns to forecast subsequent discrete codebook tokens.

🎲 3. Monte Carlo Fan Sampling

Rather than generating a fragile single-point prediction, the model performs stochastic autoregressive sampling ($N=30$ simulation paths) to map the full posterior distribution and uncertainty cone.

📈 4. Derivative Alpha Synthesis

Derived forecast trajectories are synthesized into actionable quantitative trading signals, integrated with dynamic stop-loss, position sizing, and Indian Options/Futures execution rules.

About The AlgoGPT Project

AlgoGPT is an open-source initiative designed to bridge foundational time-series language models with systematic trading in the Indian equity derivatives ecosystem. Built on PyTorch and modern Hugging Face infrastructure, it supports end-to-end data ingestion, tokenizer fine-tuning, autoregressive inference, and walk-forward backtesting.
